# Source Quality

Use this reference when the tutorial depends on evidence, authority, current facts, or precise attribution.

## When to Refresh Sources

Browse or otherwise verify current sources when the topic involves:

- laws, standards, policies, prices, schedules, product features, APIs, model behavior, or active research
- "latest", "current", "today", "recent", or similar wording
- direct quotes, citations, links, or precise source attribution
- recommendations that may affect money, time, health, legal exposure, or security

If browsing is unavailable, say which claims are based on existing knowledge and which may need live verification.

## Source Ladder

Use the highest available tier:

1. Primary rules and specifications
   Official standards, laws, API docs, product docs, regulatory guidance, source code, datasets.

2. Research and education
   Peer-reviewed papers, textbooks, university courses, lab pages, professional society resources.

3. Established professional guidance
   Government service manuals, design systems, engineering handbooks, medical or legal associations, major vendor architecture guides.

4. Field influence
   Widely cited books, essays, conference talks, case studies, postmortems, or expert blogs.

5. Community context
   Forums, social posts, issue threads, and anecdotal material. Use this to understand pain points, not to establish core facts.

## Search Pattern

Search in passes:

1. Vocabulary pass
   Find the canonical terms, alternate names, and field boundaries.

2. Authority pass
   Find primary sources, standards, official docs, or textbooks.

3. Consensus pass
   Find what several respected sources agree on.

4. Disagreement pass
   Look for known controversies, changed guidance, or outdated claims.

5. Teaching pass
   Find examples, diagrams, or explanations that reveal where learners get confused.

## Attribution Rules

Use links or citations for factual claims that are hard to verify from common knowledge. Keep quotations short and only quote when wording matters. Prefer paraphrase for teaching flow.

When sources conflict, write the practical distinction:

- what each source claims
- why the disagreement exists
- what a learner or practitioner should do with the difference

Do not inflate weak evidence. A single blog post can inspire an example, but it should not become the main authority for a field.
